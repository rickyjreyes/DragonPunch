# DragonPunch / Casual Wars

An archived game project containing a playable-format Windows executable and a compressed GMX-format project archive. The original repository description is simply “Game”; the filenames retain different names, so this README preserves both rather than inventing an authoritative release title or gameplay description.

## Files

| File | Description |
| --- | --- |
| `DragonNutPunch.exe` | Historical Windows executable supplied in the repository. |
| `CasusalWars.gmx.zip` | Archived GMX-format game project (filename spelling preserved). |

The `.gmx` project format is associated with older GameMaker development workflows. The compressed source archive's internal files, exact editor version, game mechanics and controls have **not** been independently verified here.

## Opening the project

1. Download and extract `CasusalWars.gmx.zip`.
2. Inspect the extracted project and asset directories.
3. If it includes a GameMaker `.project.gmx` file, try opening it with a compatible legacy GameMaker Studio environment. Modern GameMaker versions may require conversion.

## Running the historical build

`DragonNutPunch.exe` targets Windows. Download and inspect it before running; this is an old binary with no current compatibility or security testing recorded in the repository. It is not necessary to run the binary to browse the project archive.

## Status

Historical game/coursework archive, last updated in 2017. No build automation, gameplay documentation, source-level test suite or license file is checked in at repository root. The executable and GMX archive are preserved as original artifacts.
